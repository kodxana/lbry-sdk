# Contributing to LBRY SDK NG

This is a community-maintained fork of LBRY SDK, independent of LBRY Inc.
Contributions are welcome; the original project's compensation program does
not apply to this fork.

Report bugs and propose changes in the
[fork's issue tracker](https://github.com/kodxana/lbry-sdk-ng/issues). Include
your operating system, Python version, SDK revision and steps to reproduce.
Remove private information from logs before sharing them.

Keep pull requests focused, explain the behavior being changed, and include
regression tests for fixes. Follow the [testing guide](docs/testing.md) for
isolated wallet and integration tests using temporary data and regtest funds.
State which checks you ran and any that you could not run.

For suspected vulnerabilities, follow [SECURITY.md](SECURITY.md).

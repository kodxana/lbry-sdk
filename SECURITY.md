# Security Policy

## Maintenance scope

LBRY SDK NG is maintained by the community, independently of LBRY Inc.
Maintenance currently focuses on this repository's `master` branch. See the
[test baseline](docs/testing.md) and [compatibility audit](docs/python-compatibility.md)
for validation coverage and known dependency limitations.

## Reporting a Vulnerability

Contact [@kodxana](https://github.com/kodxana) to arrange private disclosure
before sharing vulnerability details. If you open an issue to request contact,
keep it free of exploit details, wallet seeds, private keys and personal data.

The original project's email addresses and security policy do not provide a
reporting channel for this fork. Community maintenance does not include a
guaranteed response time.

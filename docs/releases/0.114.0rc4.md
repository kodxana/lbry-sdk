# LBRY SDK NG 0.114.0rc4

This community-maintained candidate fixes issues found while testing the rc2
Windows executable against public LBRY services. It is maintained independently
of LBRY Inc. The Python package remains `lbry` and the executable remains `lbrynet`.

Rc3 was tagged but not published: its release checks twice hit an existing
timing assumption in the blob idle-timeout test. Rc4 retains its runtime fixes
and tests timeout boundaries with a controlled clock. Real socket transfers
still check connection reuse. The rc3 tag remains unchanged.

## Changes since rc2

- A failed DNS lookup for one DHT bootstrap host no longer prevents joining
  through the other configured hosts. The node retries when every host fails.
- Daemon log files use UTF-8, including after log rotation. Content titles with
  characters outside the Windows system encoding no longer cause lost entries.
- Wallet reconnects and shutdown cancel and await their background wait tasks.
  Repeated reconnects no longer leave event waiters or retry timers behind.
- Failed, timed-out or cancelled download startup stops its DHT peer search and
  clears the stream's running state so another attempt can start.
- Packaged wallet lifecycle tests reject unfinished-task warnings at shutdown.
  Logging, download startup and idle-timeout tests run on Windows and Intel macOS.

There are no wallet format, transaction protocol or dependency changes since
[rc2](./0.114.0rc2.md).

## Platforms and validation limits

The bundled runtime is CPython 3.13. Supported executable targets are Windows
x64, Linux x86-64 with glibc 2.36+, and Intel macOS 15+. The executables are
unsigned; macOS builds are not notarized. Python 3.14, Apple Silicon and musl
are not release targets. Source requirements remain in [INSTALL.md](../../INSTALL.md).

Publication requires the full CI matrix, including isolated regtest suites and
packaged wallet creation, encryption, legacy-format compatibility and restart
checks. The packaged wallet tests use disposable regtest keys and a loopback
Hub stub. Windows retains five wallet-test skips; Windows and macOS retain two
configuration-test skips. CI reports accompany the release assets.

Live rc2 Windows testing covered header synchronization, search, resolution,
free content download, interrupted download recovery and wallet reconnection
with a new empty wallet. After the fixes, the rc3 PR executable passed header
synchronization, repeated reconnects, Unicode logging, free downloads and
retry after a forced download timeout, with five clean shutdowns. These live
checks used empty wallets with blob hosting disabled. They did not exercise
paid content or an existing funded wallet.

Exchange-rate feed failures remain unresolved. A separate intermittent Windows
blob-server shutdown timeout was reproduced on the earlier code and remains
open; the live checks above do not validate hosting. A full-size mainnet Hub
snapshot has not been tested.

Keep a separate wallet backup and the previous environment before evaluating
this prerelease with existing funds.

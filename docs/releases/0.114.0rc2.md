# LBRY SDK NG 0.114.0rc2

This community-maintained candidate adds automated prerelease publication and
checks the packaged applications through wallet creation, encryption and
restart. It is maintained independently of LBRY Inc. The Python package remains
`lbry` and the executable remains `lbrynet`.

## Changes since rc1

- Each Windows, Linux and Intel macOS executable must start its daemon and pass
  the wallet lifecycle checks before it can be included in a release. The test
  creates a temporary wallet, verifies encryption on disk, rejects a wrong
  password, unlocks it, and checks the same keys and addresses after restarting.
  It also checks that removing the password persists across another restart.
- Fixed plaintext and encrypted wallets written with SDK 0.113.0 on Python 3.9
  check compatibility with the pre-upgrade wallet format. Tests compare keys
  and derived addresses with recorded legacy values, then change the password
  and reopen the saved wallet in another daemon process.
- Version tags publish prereleases only after the full test matrix passes.
  Assets include the tested executables, checksums, source/run metadata and CI
  reports. Publication verifies the SDK and pinned Hub revisions, tag, artifact
  hashes and uploaded GitHub digests. See [the release process](../releasing.md).

There are no wallet format, transaction protocol or dependency changes since
[rc1](0.114.0rc1.md).

## Platforms and validation limits

The bundled runtime is CPython 3.13. Supported executable targets are Windows
x64, Linux x86-64 with glibc 2.36+, and Intel macOS 15+. The executables are
unsigned; macOS builds are not notarized. Python 3.14, Apple Silicon and musl
are not release targets. Source installation requirements remain in
[INSTALL.md](../../INSTALL.md).

The packaged wallet tests use temporary directories, regtest keys and a
loopback Hub stub with no blocks or transaction history. Linux runs them inside
the build container with external networking disabled. Existing isolated
regtest suites exercise real Hub connections, transactions, claims and data
transfers. Windows retains five wallet-test skips, and Windows/macOS retain
two configuration-test skips; CI logs record the reasons.

No real wallet or full-size mainnet Hub snapshot has been tested. Preserve a
separate wallet backup and the previous environment before evaluating this
candidate with existing funds. This release does not resolve every inherited
upstream issue.
